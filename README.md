Resumen del Proyecto: Estrategia DLP - TechCorp Inc. 🛡️

Este repositorio contiene el marco estratégico de Prevención de Pérdida de Datos (DLP) diseñado para proteger los activos digitales de TechCorp Inc.. La estrategia asegura la confidencialidad de soluciones de software en sectores de finanzas y salud, garantizando el cumplimiento de normativas como el GDPR.  

📋 Pilares de la Estrategia

1. Clasificación de Información
 Los datos se categorizan para aplicar niveles proporcionales de protección:
   Públicos: Información de libre divulgación como comunicados de prensa. 
   Internos: Procedimientos operativos y políticas de departamentos como RRHH y Ventas.
   Sensibles: Propiedad intelectual (código fuente), datos financieros y PII de clientes

   2. Control de Acceso y Gestión de Privilegios
      Se implementa el Principio del Menor Privilegio (PoLP)
      Los empleados acceden exclusivamente a la información necesaria para sus funciones.  Revisión Trimestral: Los Gerentes de Área y el departamento de TI validan y ajustan permisos periódicamente.

3. Monitoreo e Infraestructura Tecnológica
   TechCorp utiliza su infraestructura de red y nube para la vigilancia activa:
   SIEM y Herramientas DLP: Detección de anomalías en tiempo real y bloqueo de transferencias no autorizadas.
    Auditoría: Revisión mensual de registros de actividad para identificar incidentes sospechosos.

   4. Medidas de Prevención de Filtraciones
      Protección proactiva de los datos en todos sus estados:
      Cifrado: Aplicado de forma obligatoria tanto en reposo como en tránsito.  
      Control de Endpoints: Restricción de dispositivos USB y cifrado automático de medios externos.

5. Cultura de Ciberseguridad
 Capacitación continua del equipo de 200 empleados de TechCorp:
 Formación: Capacitaciones semestrales obligatorias sobre riesgos y mejores prácticas.
 Práctica: Simulaciones de phishing para fortalecer la detección de amenazas externas.
